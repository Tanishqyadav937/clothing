# Deployment Guide

This file will contain deployment instructions for all components.

Components to deploy:
1. Signaling server (Node.js + Express + Socket.io)
2. TURN server (coturn) on a public VPS
3. Mobile app (Flutter, to Google Play and Apple App Store)
4. Web client (React, to a CDN or static host)
5. Database (Firestore or PostgreSQL)

See the main project document (webrtc-calling-app-project.md) for deployment architecture (§2.6).
